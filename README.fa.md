# BLACKOUT: STRIKE FORCE MOBILE

نسخهٔ ارتقایافتهٔ نمونهٔ شوتر اول‌شخص سه‌بعدی برای مرورگر موبایل و رایانه.

## محتویات ZIP
- `index.html`: فایل اصلی بازی. آن را در ریشهٔ مخزن GitHub قرار بده.
- `README.fa.md`: همین راهنما.

## انتشار رایگان با GitHub Pages
1. وارد GitHub شو و یک مخزن جدید بساز، مثلاً `blackout-strike-force`.
2. مخزن را Public انتخاب کن تا GitHub Pages رایگان قابل استفاده باشد.
3. محتوای ZIP را استخراج کن و `index.html` و `README.fa.md` را مستقیماً در ریشهٔ مخزن آپلود کن. فایل‌ها را داخل یک پوشهٔ اضافی قرار نده.
4. وارد `Settings` → `Pages` شو.
5. در `Build and deployment`، گزینهٔ `Deploy from a branch` را انتخاب کن.
6. شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و `Save` کن.
7. چند دقیقه صبر کن تا GitHub لینک سایت را نشان بدهد.

## نیازمندی اینترنت
این نسخه فایل Three.js را از `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js` بارگیری می‌کند. بنابراین برای بارگیری اولیهٔ موتور، اینترنت و دسترسی به این دامنه لازم است. بازی سرور آنلاین اختصاصی نمی‌خواهد، اما این ZIP کاملاً آفلاین نیست.

## کنترل‌ها
### موبایل
- دکمه‌های جهت‌دار: حرکت
- کشیدن انگشت در نیمهٔ راست صفحه: چرخاندن دوربین و نشانه‌گیری
- شلیک: نگه‌داشتن دکمهٔ شلیک
- خشاب: بارگذاری مجدد
- تعویض سلاح: جابه‌جایی بین تپانچه و تفنگ
- توقف: بازکردن منوی توقف

### رایانه
- `W A S D`: حرکت
- ماوس: نگاه و نشانه‌گیری
- کلیک چپ: شلیک
- `R`: تعویض خشاب
- `1` و `2`: انتخاب سلاح
- `Shift`: دویدن
- `Esc`: توقف

## محدودیت‌های شفاف
- این نسخه تک‌نفره و دارای ربات‌های ساده است، نه بازی آنلاین چندنفره.
- مدل‌های شخصیت، سلاح و محیط ساده و تولیدشده با هندسهٔ داخل کد هستند؛ فایل‌های گرافیکی حرفه‌ای یا انیمیشن‌های موشن‌کپچر در بسته نیستند.
- عملکرد روی گوشی‌های مختلف یکسان نیست. برای دستگاه ضعیف‌تر، تب‌های اضافی مرورگر را ببند و کیفیت گرافیک را از تنظیمات مرورگر/دستگاه پایین بیاور.
- این پروژه الهام‌گرفته از سبک شوترهای تاکتیکی است و از فایل‌ها یا دارایی‌های اختصاصی Counter-Strike استفاده نمی‌کند.


## نصب به شکل PWA
این بسته شامل `manifest.webmanifest`، آیکون برداری `icon.svg` و `sw.js` (سرویس‌ورکر) است.
پس از انتشار روی GitHub Pages با HTTPS:
1. لینک سایت را در Chrome اندروید باز کن.
2. از منوی سه‌نقطه، `Install app` یا `Add to Home screen` را انتخاب کن؛ نام گزینه بسته به نسخهٔ Chrome فرق دارد.
3. اولین اجرا باید آنلاین باشد تا فایل‌های بازی و موتور سه‌بعدی بارگیری و در صورت امکان cache شوند.
نکته: وجود manifest و service worker نصب PWA را فراهم می‌کند، اما تضمین نمی‌کند همهٔ مرورگرها همیشه دکمهٔ Install را نشان دهند. آفلاین بودن کامل به دریافت موفق و cache شدن موتور Three.js هم وابسته است.
